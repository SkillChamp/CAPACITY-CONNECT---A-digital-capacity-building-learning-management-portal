# Capacity Connect — MoES Prototype

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Select Trainee, Trainer or Admin.
4. Enter any email and password `demo123`.

## Included
- Role-based login prototype
- Trainee dashboard: courses, library, assessments, certificates, profile, competency map, feedback, notifications
- Trainer dashboard: courses, questionnaire builder, library, participants, performance, competency mapping, profile
- Admin dashboard: approvals, user/role management, courses, enrollments, analytics, certifications, participation, competency mapping, publishing
- Responsive desktop/tablet/mobile layout
- Light theme with role-specific blurred dashboard backgrounds
- Interactive demo modals, navigation, tables, progress cards and localStorage role persistence

## Production warning
This is a front-end prototype. It does NOT provide production authentication or authorization. A real deployment needs a backend, HTTPS, server-side role checks, secure sessions/cookies, password hashing, validation, audit logging, file upload controls, CSRF/XSS protections and appropriate access controls.
